- **sels-bains-floraux** → `sel de bain` ; LT: relaxant, Himalaya, fleurs séchées, Epsom, bain floral, aux HE, détente.
- **soins-corps** → `soin du corps naturel` ; LT: crème hydratante, beurre karité, gommage, huile bio, lait peau sèche, gommage sucre.
- **savons-artisanaux** → `savon artisanal` ; LT: saponifié à froid, surgras peau sensible, bio, peau sèche, charbon peau grasse, sur corde, exfoliant. Segmenter par type de peau.
- **fleurs-savon** → `fleur de savon` ; LT: bouquet, cadeau, parfumé, coffret, Saint-Valentin, fête des mères. 100% cadeau, saisonnier.
- **soins-visage** → `soin visage naturel` ; LT: masque argile (verte=grasse/blanche=sensible/rose), sérum bio, baume lèvres, tonique, huile visage. Segmenter par couleur d'argile.
- **soins-cheveux** → `shampoing solide` ; LT: cheveux gras/secs, zéro déchet, sans sulfate, sérum capillaire, bio, après-shampoing solide. Segmenter par nature de cheveu.
- **accessoires-bain** → `accessoire de bain` ; LT: éponge konjac (phare), rouleau pierre, loofah, gant exfoliant, pierre ponce, brosse sèche.
- **steamers-douche** → `galet de douche` (terme FR dominant, pas "steamer") ; LT: aromathérapie, eucalyptus, effervescent, vapeur menthe, relaxant, pastille HE.
- **porte-savons** → `porte-savon` ; LT: bois, pierre, design naturel, zéro déchet.

## Principe SEO directeur

Le marché bien-être FR se structure sur **deux axes croisés** que tous les leaders exploitent :

1. **Par FORMAT / produit** — c'est votre arborescence actuelle (huiles, bougies, bracelets…).
2. **Par BIENFAIT/BESOIN** (huile essentielle sommeil, pierre anti-stress…) **et par ENTITÉ NOMMÉE** (par plante, par pierre, par famille olfactive, par senteur).

👉 Un même produit vit dans **plusieurs collections via des tags/filtres** → multiplie les pages d'atterrissage SEO sans dupliquer le stock. C'est le modèle France Minéraux / Aroma-Zone / Maison Berger.
